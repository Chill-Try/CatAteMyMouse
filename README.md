# CatAteMyMouse

猫吃掉了我的鼠标

AutoHotkey v2 脚本，旨在减少鼠标依赖

## 功能

1. 通过键盘，**遍历聚焦**窗口内的**文本框** 
2. 极简且快速的**窗口切换** 
3. 关灯，**聚光灯**汇聚当前窗口
4. **半透明**非聚焦窗口

## 脚本

- `AltTab.ahk`：极简的、可自定义的 Alt+Tab 窗口切换、Alt+数字键 切换指定程序窗口
- `AltEsc.ahk`：在当前窗口内切换文本框焦点
- `Ghoster_V2.ahk`：保持专注，对非活动窗口做暗化处理
- `DynamicWindowTransparency.ahk`：将当前聚焦窗口设为不透明，非焦点窗口变为半透明

## 依赖

- [AutoHotKey v2 下载](https://www.autohotkey.com/) 

## 如何使用

1. 安装 AutoHotkey v2；
2. 下载本仓库中的脚本；
3. 运行想要的 `.ahk` 脚本。
